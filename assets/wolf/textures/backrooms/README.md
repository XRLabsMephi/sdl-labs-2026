# Backrooms textures

Generated with the built-in `image_gen.imagegen` tool, one call per texture.
Original PNG outputs were copied into this directory without image editing.
All three are RGB textures; the glass material uses opacity 96/255 at load time.
PNG alpha, when present in other assets, is multiplied by this material opacity.

## wallpaper.png — exact prompt

Use case: stylized-concept. Asset type: single seamless square diffuse wall texture PNG for a software raycaster game, Backrooms Level 0 mood. Primary request: aged sickly mustard yellow wallpaper with a tiny repetitive faded ochre damask pattern, subtle damp stains and paper fibers. Composition: orthographic perfectly flat face-on material scan, the material fills the entire square, no perspective, no room view, no objects, no borders, no text, no watermarks. Even neutral illumination baked into albedo, no cast shadows or vignette. Low contrast worn surface with believable grain. All edges must tile seamlessly. One texture only. 512x512 if possible.

## panels.png — exact prompt

Use case: stylized-concept. Asset type: single seamless square diffuse wall texture PNG for a software raycaster game in the Backrooms style. Primary request: old beige cream painted office wall panels, faint vertical joins, tobacco yellow discoloration, subtle peeling paint and worn bottom stains. Composition: orthographic perfectly flat face-on material scan; all of the square is the wall surface, no perspective, no room view, no objects, no text or watermarks, no border. Even flat illumination without cast shadows. Muted warm beige and ochre, compatible with yellow Backrooms wallpaper. Seamlessly repeating edges. One texture only. 512x512 if possible.

## glass.png — exact prompt

Use case: stylized-concept. Asset type: single square diffuse texture PNG for a transparent office partition in a Backrooms raycaster game. Primary request: dusty pale green frosted office glass in a thin worn dull beige metal frame at all four edges, subtle vertical ribbing and a few scratches. Perfectly flat orthographic front view of just the square panel, full frame fills the image, no perspective or background scene, no room, no objects, no lettering, no watermarks. The glass itself has a pale muted olive-gray color; the game applies material alpha separately. Even neutral illumination, subtle albedo texture, no strong highlights or cast shadows. One texture only. 512x512 if possible.
